# Соответствие стандартам

Проект не проходил сертификацию. Мы **ориентируемся** на перечисленные стандарты: для каждого указано, что именно делаем, где это в репозитории и в каком оно состоянии. Статусы: **сделано**, **в работе**, **план** (после хакатона), **не применимо** (с причиной).

## Классификация системы

| Вопрос | Ответ |
| --- | --- |
| Что делает система | Помогает импортёру лекарств планировать закупки, логистику и контракты при регулируемых ценах |
| Медицинское изделие? | Нет. Не диагностирует, не лечит, не влияет на назначение. IEC 62304 и ISO 13485 не применимы |
| GxP-система? | Нет. Не управляет производством, качеством и не хранит GxP-записи. 21 CFR Part 11 не применим. Принципы целостности данных (ALCOA+) берём как хорошую практику |
| Персональные данные | Не обрабатываем: нет данных пациентов и врачей. Закон Республики Узбекистан «О персональных данных» не затрагивается |
| Коммерческая тайна | Затраты импортёра конфиденциальны: система работает локально, без отправки данных наружу (LLM-слой отключаемый) |
| Класс риска ИИ | Поддержка решений для бизнеса, человек принимает решение. Ошибка опасна дефицитом лекарства, поэтому запас не меньше месяца — жёсткое правило |
