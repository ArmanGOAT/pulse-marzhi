# ADR-0004. Границы LLM-слоя

- Статус: принято; LLM-слой в прототип хакатона не вошёл, правила ниже действуют, когда его добавят
- Дата: 2026-11-17

## Контекст
LLM удобна для вопросов обычным языком и текста записки, но ненадёжна в арифметике и не гарантирует соблюдение ограничений.

## Решение
- План мер считает только оптимизатор. LLM не составляет план и не считает цифры.
- LLM вызывает оптимизатор, двойник упаковки и радар как инструменты. Цифры на экране берутся только из результатов инструментов.
- LLM-слой необязательный и отключаемый. Без интернета он выключен, остальная система работает.
- Данные импортёра уходят во внешний API только при включённом LLM-слое и с явным согласием пользователя.

## Последствия
- Плюс: воспроизводимые и проверяемые цифры, работа без интернета.
- Минус: ответы LLM ограничены возможностями инструментов. Принимаем.
