# ADR-0002. Своя интерактивная страница вместо Streamlit

- Статус: принято
- Дата: 2026-11-17

## Контекст
Демо продукта длится 2 минуты. Нужны три сильных момента, плавные изменения при движении ползунков и режим презентации. Streamlit перезапускает весь скрипт при каждом изменении и выглядит как типичное хакатонное приложение.

## Решение
Интерфейс — отдельная страница (`web/`: HTML, CSS и JavaScript без сборки и внешних библиотек, графики на SVG), которую отдаёт тот же FastAPI. Все расчёты выполняет только Python: ползунок курса вызывает `/api/pack` с задержкой 40 мс, ответ приходит примерно за 5 мс на локальной машине (замер curl, 18.11.2026), поэтому дублировать формулу в браузере не нужно. Дизайн-система описана в `docs/design-system.md`.

Уточнение от 2026-11-18: в первой версии решения лёгкие пересчёты планировалось дублировать в браузере. Замер показал, что API отвечает достаточно быстро, и от дублирования отказались.

## Последствия
- Плюс: интерфейс выглядит как продукт, цифры меняются во время движения ползунка, есть режим презентации.
- Плюс: работает без интернета, все файлы лежат локально.
- Минус: больше работы над интерфейсом.
- Плюс: формула упаковки существует в одном месте, страница не может разойтись с выгрузкой и тестами.
