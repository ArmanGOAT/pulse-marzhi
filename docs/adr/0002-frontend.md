# ADR-0002. Своя интерактивная страница вместо Streamlit

- Статус: принято
- Дата: 2026-11-17

## Контекст
Демо продукта длится 2 минуты. Нужны три сильных момента, плавные изменения при движении ползунков и режим презентации. Streamlit перезапускает весь скрипт при каждом изменении и выглядит как типичное хакатонное приложение.

## Решение
Интерфейс — отдельная страница (`web/`), которая получает данные от API. Лёгкие пересчёты (двойник упаковки на ползунке курса) дублируются в браузере для мгновенного отклика и сверяются с Python тестом. Тяжёлые расчёты (радар, оптимизатор, сценарии) выполняет только Python.

## Последствия
- Плюс: интерфейс выглядит как продукт, цифры меняются во время движения ползунка, есть режим презентации.
- Плюс: работает без интернета, все файлы лежат локально.
- Минус: больше работы над интерфейсом. Минус: формула упаковки есть и в Python, и в браузере, поэтому их совпадение проверяет тест.
