## ML System Design Scorecard: «Пульс маржи» (защита маржи импортёра ривароксабана 20 мг)

**Вердикт:** approve with concerns (avg 2.70) · дизайн-док → прототип хакатона, оптимизация с неопределённостью + классификация + квантильный прогноз, средне-высокий риск (непрерывность терапии, финансовые решения)
**Критичных находок:** 2 (ML может не влиять на план; потолок зависит от таможенной цены самого импортёра, и скидки на закупку отберут при пересмотре)
**Вердикт авторов:** Valerii and Arseny назвали бы это крепким черновиком: задача, антицели и цена ошибки сформулированы образцово, но связь ML с решением и сами затраты пока держатся на допущениях.

| Измерение | Оценка | Почему |
|---|---|---|
| Problem framing, goals & antigoals | A- | Перевёрнутая пирамида, цифры боли, пользователь (финдиректор), антицели; минус: ни одного разговора с импортёром, определение маржи не подтверждено |
| Cost of mistakes & risk | B+ | Асимметрия «пустой склад хуже лишнего запаса» превращена в жёсткое ограничение; нет цены ошибок радара (что делает импортёр при p=0,2 и p=0,5) |
| Prior work, build/buy & baselines | B+ | Лестница «константа → правило → модель» для каждого модуля, правило = запасной вариант; нет сравнения с тем, как импортёр решает это сейчас (Excel, консультант) |
| Metrics, loss & measurement | B- | Иерархия метрик и пороги записаны заранее; но не проверено, меняет ли вероятность радара выбранный план |
| Data, labels & features | C | 9 из 12 параметров затрат — допущения, подогнанные под 2,2%; данных пересмотров нет; корзина референтных стран сменилась в 2026 |
| Validation & leakage | B | Временной сплит декабрь 2025 → июль 2026; риск подглядывания: признак «цена к медиане с Турцией и Египтом» для декабря 2025 |
| Error analysis | D+ | Кроме AUC/Brier/top-10% ничего: нет разбора ошибок радара по группам ATC и калибровки по сегментам |
| Training pipeline & reproducibility | C | Структура репо и стек заданы; нет сидов, версий данных, сохранения артефактов |
| Serving, integration & release | B | Офлайн на ноутбуке, план < 2 с, откат на правило с пометкой на экране |
| Monitoring, ownership & maintenance | n/a (stage) | Для хакатона не нужно; переобучение радара после каждого пересмотра стоит добавить строкой в «что дальше» |

**Главное исправление:** заменить «радар на синтетике» калькулятором следующего потолка по публичной формуле (минимум из средней по референтным странам, цены в стране производства + до 15% и средней таможенной цены CIP за 12 месяцев) и пометить каждый рычаг: останется у импортёра или уйдёт в новый потолок. ML оставить там, где формула не отвечает: выберет ли агентство препарат в следующую волну.
**Вывод:** модель заслуживает места в системе только тогда, когда её выход меняет решение; AUC без этой связи ничего не доказывает.
