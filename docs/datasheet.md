# Паспорт данных «Пульс маржи»

Формат по Datasheets for Datasets (Gebru et al., 2021). Качество данных описано по ISO/IEC 25012 и
ISO/IEC 5259, происхождение каждой записи — по ALCOA+. Паспорт каждой обработанной таблицы
(число строк, SHA-256, источники, статусы) лежит рядом с ней: `data/processed/*.meta.json`.

## Зачем собраны

Чтобы предсказывать пересмотры потолка цены рецептурных лекарств в Узбекистане и считать их влияние
на маржу импортёра. Данные собрала команда хакатона в ноябре 2026 года для задачи №16.

## Состав

Персональных данных нет: только сведения о препаратах, ценах и курсах из открытых государственных источников.

## Как собраны

- Реестр: публичный API портала Агентства (mpa.uz), загрузчик `pulse.data.loaders.mpa_api`. Снимок
  на 1-е число месяца сохраняется как есть, в сжатом JSON Lines, с датой в имени файла.
- Списки пересмотров: файлы xlsx с портала, загрузчик `pulse.data.loaders.mpa`. Для каждого файла
  в `manifest.json` записаны адрес, дата загрузки и SHA-256.
- Курсы: API ЦБ РУз (cbu.uz), загрузчик `pulse.data.loaders.cbu`.
- Сырые файлы не правятся (ALCOA+: Original). Любая обработка идёт отдельным шагом и даёт новую таблицу.

## Обработка

`make data` → `pulse.data.build` и `pulse.data.registry`:

1. Нормализация текста (регистр, ®, пробелы) и разбор формы, дозировки, числа единиц и страны производителя.
2. Стабильный ключ упаковки: номер регистрации, торговое название и производитель в нормализованном виде.
3. Пересчёт цен в доллары по курсу ЦБ на дату снимка.
4. События «цену снизили на 10% и больше» между соседними снимками.

Собранная панель реестра (334 185 строк) сохраняется в `data/processed/registry_panel.parquet` с паспортом.
В паспорте есть отпечаток SHA-256 исходных снимков, курсов и кода разбора: если что-то из них поменялось,
панель пересобирается сама. Сборка из сырых файлов занимает 11–21 с, чтение готовой панели 0,1 с.
5. Таблицы курсов, цен и препаратов из `pulse.data.build` проверяются по контрактам данных
   (`pulse.data.contracts`): обязательные колонки, типы, диапазоны, уникальность ключей, валюты
   по ISO 4217. Нарушение останавливает сборку с ошибкой `DataQualityError`.
6. Таблицы читаются «на дату» (`store.as_of`): признак на дату прогноза строится только из того,
   что было известно до неё (ADR-0003, тесты в `tests/test_ml.py`).

## Известные ограничения

- Снимки помесячные: дата пересмотра известна с точностью до месяца.
- Нет цен в референтных странах, то есть главного входа формулы приказа № 3735.
- Курс на 1-е число месяца даёт шум в несколько процентов при пересчёте цен в евро и рублях.
- Старые снимки неполные: признак «рецептурный» в них пуст, поэтому рецептурным считается всё,
  где он не равен «Без рецепта».
- Затраты импортёра — оценка команды. Их нужно заменить данными конкретного импортёра.

## Использование

- Подходит для оценки вероятности пересмотра и для сценарного анализа маржи.
- Не подходит для решений о лечении, для юридической оценки цен и для оценки конкретных компаний.

## Распространение и обновление

Данные взяты из открытых государственных источников, в репозитории лежат только загрузчики и паспорта.
Сырые снимки не коммитятся (`.gitignore`), а скачиваются командой `make data`.
`make data` скачивает снимки строго по 17.11.2026, поэтому цифры из документов воспроизводятся в любой день;
SHA-256 каждого снимка записан в `data/raw/mpa_api/manifest.json`. После новой волны пересмотров: `make data-latest && make train`. Новый запуск появится
в `artifacts/experiments/`, а прежние сохранятся для сравнения.
